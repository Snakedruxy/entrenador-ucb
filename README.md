# Entrenador UCB + CUSUM

Entrenador para optimizar tu práctica en juegos de ritmo.

## Características
- UCB Adaptado (exploración/explotación)
- CUSUM (detección de cambios estadísticos)
- Regresión Lineal (tendencias de empeoramiento)
- Subes al 95% de promedio, bajas si < 85%
- Mínimo 2 intentos para subir de nivel
